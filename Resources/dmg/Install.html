DarkNotch

Golden Gate · 27

Установка за две минуты

DarkNotch создан для macOS 27 Golden Gate, где многие прежние менеджеры строки меню перестали работать. Приложение может запуститься и на более старых версиях, но цель — именно 27-я.

Приложение не подписано платным сертификатом Apple, поэтому первый запуск macOS заблокирует. Это ожидаемо — ниже три способа открыть его.

Installed in two minutes

DarkNotch is built for macOS 27 Golden Gate, where many older menu bar managers stopped working. It may launch on older releases too, but 27 is the target.

The app has no paid Apple certificate, so macOS blocks the first launch. That is expected — below are three ways to open it.

  1. Перетащите DarkNotch в Applications

    Откройте этот образ в Finder и перетащите иконку DarkNotch на папку Applications слева.

    Drag DarkNotch into Applications

    Open this disk image in Finder and drag the DarkNotch icon onto the Applications folder.

  2. Снимите блокировку первого запуска

    Откройте Applications и запустите DarkNotch. Появится предупреждение — закройте его и используйте один из способов:

    1 · Системные настройки — macOS 15 и новее

    Откройте Системные настройки → Конфиденциальность и безопасность. Прокрутите до раздела Безопасность и нажмите Открыть всё равно, затем подтвердите паролем.

    2 · Правый клик — macOS 13–14

    В Applications нажмите на DarkNotch правой кнопкой → Открыть → в диалоге снова Открыть.

    3 · Терминал — любая версия

    Уберите карантин и запустите приложение:

    $ xattr -dr com.apple.quarantine /Applications/DarkNotch.app
$ open /Applications/DarkNotch.app

    Эти две строки можно вставить в Терминал целиком.

    Allow the first launch

    Open Applications and launch DarkNotch. A warning appears — dismiss it and use one of these:

    1 · System Settings — macOS 15 and later

    Open System Settings → Privacy & Security. Scroll to the Security section and click Open Anyway, then confirm with your password.

    2 · Right click — macOS 13–14

    In Applications, right-click DarkNotch → Open → Open again in the dialog.

    3 · Terminal — any macOS version

    Remove the quarantine flag and launch the app:

    $ xattr -dr com.apple.quarantine /Applications/DarkNotch.app
$ open /Applications/DarkNotch.app

    You can paste both lines into Terminal at once.

  3. Разрешите Accessibility

    DarkNotch живёт в строке меню. Чтобы работали Hide App Menus и Hide Menu Bar Icons, включите доступ: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ.

    Если macOS забудет разрешение после обновления, удалите DarkNotch из списка кнопкой − и добавьте снова.

    Allow Accessibility

    DarkNotch lives in the menu bar. For Hide App Menus and Hide Menu Bar Icons to work, enable it in System Settings → Privacy & Security → Accessibility.

    If macOS forgets the permission after an update, remove DarkNotch from the list with − and add it again.

  4. Обновления

    Приложение проверяет обновления само через Sparkle. Вручную: Проверить обновления… в меню DarkNotch. Новые версии ставятся без повторного DMG.

    Updates

    The app checks for updates through Sparkle. Manually: Check for Updates… in the DarkNotch menu. New versions install without downloading the DMG again.

Удаление: Quit DarkNotch → удалите /Applications/DarkNotch.app.
Uninstall: Quit DarkNotch → delete /Applications/DarkNotch.app.
